This website runs on [Jekyll](https://jekyllrb.com/) and lives on GitHub Pages. The infrastructure is borrowed the [Lagrange](https://github.com/lenpaul/lagrange) theme, so this is a mod. This post is the kitchen-sink tour, showing all possible formats, in one place, so I can check nothing has broken (and for use as a cross reference when I soon forget everything).

## Words

We have *italics* for emphasis, **bold** for when emphasis isn't enough, and ***bold italics*** for emergencies. Inline code looks like `print("hello, world")`, and [links](https://en.wikipedia.org/wiki/Quokka) look like that.

Lists can either be numbered:

1. Old MacDonald
2. Had
3. A farm

Or bullet pointed:

- Hello
- there

and a blockquote, for quotation:

> "All models are wrong, but some are useful."
>
> — George Box

## Code

Code is coloured by language. Here's how it looks in Python:

```python
for n in range(1, 16):
    if n % 15 == 0:
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)
```

And in R:

```r
rolls <- sample(1:6, size = 1000, replace = TRUE)
table(rolls)
mean(rolls)  # should be close to 3.5
```
